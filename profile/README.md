# I'll Be Backend

**Watch messy code get better, step by step.**

Programming lessons that start from working code with a real problem in it, then refactor it one small, safe step at a time. Each lesson is a video, an interactive page you can step through, and code for every step.

[illbebackend.dev](https://illbebackend.dev) · [YouTube](https://www.youtube.com/@illbebackend)
